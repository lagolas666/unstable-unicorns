# ТЗ Бэкенду: пять нереализованных видов действий в executor.ts

Дата: 30.10.2026. Автор: Единорог Аналитик. Владелец кода: Бэкенд (server/src/engine/executor.ts).

## Факты (проверено чтением кода и unicorns.json)

- В executor.ts `executeAction` (L730) для неизвестного вида уходит в `default` (L1519–1523): `console.warn('unhandled action kind: …')` и `return false`. Состояние не меняется.
- Вид `draw` обрабатывается до `switch` (L734) по приведению типа, потому что его нет в union `ActionKind` (shared/src/types.ts L66–90). Добавление `case` в switch ломало 12 сьютов (TS2678). Тот же приём или осторожное расширение union — решение Бэкенда, с прогоном tsc.
- `server/data/unicorns.json` — вики-дамп: структурированных эффектов нет, есть только текст `Card Texts` (часть текста повреждена). Источник правды для эффектов — код executor.ts, блоки `nameLower.includes(...)` (L374–551) и поле `effects` карт.

## Решения Аналитика (по мандату 29.10.2026, без вопроса Даниилу)

1. **counter** — не реализовывать как отдельный вид, пока нет карты, которой он нужен вне окна Neigh. Бэкенд подтверждает фактами (grep по unicorns.json и окнам).
2. **choice** (Espresso Oracle) — не блокировать релиз: оставить текущую логику по условию, зафиксировать в отчёте как отклонение от текста карты. Полноценный выбор — отдельная задача с UI.
3. **force_discard** — случайная карта из руки цели (детерминировано через state.deck-подобный RNG, как в shuffle_deck, или `Math.random` с явным комментарием).
4. **pull** — случайная карта из руки выбранного соперника; если рука пуста, возвращать false без мутаций.
5. **return_to_hand** — реализовать как замену перемещения: при sacrifice/destroy Единорога в стойле владельца с Zombie Knight карта уходит в руку владельца вместо сброса.

## Что проверяем после реализации

- Существующий тест **server/test/drawExecutor.test.ts L143–159** проверяет, что все пять видов дают `false` и предупреждение. После реализации этот тест станет ложным **по замыслу**. Правка теста — только через Тестировщика (server/test/** принадлежит ему). Бэкенд не правит тесты.
- Новые тесты на каждый реализованный вид: позитив (состояние изменилось как по тексту карты) и негатив (пустая рука / нет цели — состояние не меняется).
- Мутации: на каждый вид — одна мутация в executor.ts, красный тест, возврат файла по sha256.
- Гейт: сервер jest (baseline 23 сьюта; 310 passed / 3 skipped на последнем прогоне Тестировщика, сверять с актуальным baseline), tsc --noEmit, клиент tsc и vite build — без регрессий.
- Файл executor.ts CRLF — правка через LF-анкеры и обратная конверсия в CRLF (правило #54). Проверка: match(/\r\n/g).length и отсутствие голых \n.
- Кодировка: проверка результата скриптом на U+FFFD, не глазами в консоли.
