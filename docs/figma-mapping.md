## 4. Что переносится точно, а что нет

**Переносится 1:1:** сетка 1920×1080 и координаты зон, размеры карт, 22 компонента и их состояния, палитра, шрифты, скругления, тени, 119 SVG-иконок, все 75 текстов стола.

**Переносится приближённо:**

- `NOISE`-текстуры (6 слоёв) — только PNG-подложкой, CSS-шум даёт другой характер;
- 9 иллюстраций карт — только растром (45 IMAGE-заливок, 9 уникальных), векторной графики в них нет;
- 9 векторов не рендерятся через API (`visible=false` в самом макете): 123:3358, 123:3355, 123:3354, 123:3150, 123:3147, 123:3146, 123:3157, 123:3154, 123:3153 — это скрытые «каменные» накладки кнопок, в коде заменяются CSS-градиентом;
- анимации переходов (в макете статичные состояния) — задаём сами.

**Не переносится:** адаптив (мобильных фреймов нет вообще — только desktop 1920), состояния данных (макет с одним ходом и 2 игроками), интерактив (hover/press — только как статичные варианты).

**Ограничение проверки:** REST API отдаёт геометрию и стили, но не пиксель. Сверка идёт по числам, не «на глаз» — поэтому визуальную приёмку делает Даниил по скриншотам.
