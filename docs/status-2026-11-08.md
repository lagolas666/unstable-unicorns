## 2. Что реализовано и принято

### 2.1 Движок и правила партии
- **Архитектура**: `routes/game.ts` — только транспорт (34 маршрута, 1162 строки, из них вынесено хранилище), `gameStore.ts` (102 строки) — общий `Map` игр для REST и socket, `gameService.ts` (2386 строк) — логика, `engine/executor.ts` — исполнение эффектов, `stateView.ts` — контракт состояния. Решение от 28.10 о выносе движка выполнено.
- **Socket-слой полного движка**: `socket/handlers.ts` (310 строк) — 7 событий `join_game`, `leave_game`, `play_card`, `draw_card`, `end_turn`, `resolve_pending`, `react`. Это закрывает разрыв «два движка»: полный движок доступен не только через `/playtest`.
- **Победа**: 7 единорогов (6 при 6–8 игроках), `getWinningScore` с зажимом 2–8, ноль хардкодов `>= 7` в `gameInstance.ts`.
- **Фазы и ход**: Beginning → Draw → Action → End, лимит руки 7, BUG-01 (окно `hand_limit` 5 с, ход только после руки ≤7, автосброс запрещён) закрыт и под стражем.
- **Конец партии**: только при пустых колоде и сбросе, иначе 409 с `gameOver:true` и `winnerId` без мутаций.

### 2.2 Реакции (окно Neigh)
14 методов `react/*` в `gameService`: neigh, super_neigh, redirect, shield, hypnorog, rewind, intercept, intercept_steal, counter_neigh, prevent, ignore_target, frankencorn_intercept, play_as_instant, objection. Окно 5 с, `canReact` считается на сервере (`data/canReactFlags.ts`), клиент правила не дублирует. BUG-02 (отменённая Neigh уходит в сброс) закрыт.

### 2.3 Swap — самая дорогая линия, закрыта целиком
Цепочка BUG-SWAP-03 → 04 → 05 → follow-up → N-1 принята:
- BUG-SWAP-03 (размножение карт на 3+ игроках) — закрыт, `swapOpponentCandidates`.
- BUG-SWAP-05 (терминальный отказ без окна выбора) — страж `swapTransport.test.ts`, 7 кейсов.
- follow-up (асимметрия предпроверки и исполнения) — `actorId` протянут в 5 точках.
- N-1 (явный выбор соперника шёл мимо фильтра) — закрыт, две мои мутации M-N1a/M-N1b красят именно этот путь.
- Ветка «2 игрока» — `owners.length <= 1` больше не выходит до фильтра.
- **Страж `swapCandidates.test.ts`** (N1–N4) принят 08.11.2026: на дефектном коде до правки падает N1 (`reads: 0 → 1`), зелёный после; четыре моих мутанта M-A1…M-A4 ловятся, откат побайтовый.

### 3.4 Добор: решафл есть только в официальном доборе, в доборе эффектами — нет
**Уточнено по коду 08.11.2026 (первая редакция отчёта здесь ошибалась).**
- Официальный добор хода — **сделан**: `gameService.ts` L1044–1052, при пустой колоде сброс перетасовывается Фишером–Йетсом, пишется лог `reshuffle`, затем `maybeEndOnDeckEmpty` (`engine/leader.ts`, пусты и колода, и сброс — только тогда конец партии).

- `mill_until` (L1962) корректно отказывает при пустой колоде — это не дефект, а явный отказ.
Дефект у́же, чем звучал в первой редакции: ломается только добор по эффекту, официальный добор закрыт.
