## BUG-01 — Лимит руки не сбрасывается, ход блокируется (High)

**Баг:** при руке больше 7 карт `endTurn` возвращает 400 и ход не передаётся; автосброса до лимита нет.

**Шаги воспроизведения:**
1. Создать партию на 2 игроков, у `p1` в руке 8 карт, фаза `end`.
2. `POST /api/game/:id/endTurn`.
3. Прочитать состояние.

**Ожидаемое поведение:** по правилам UU в конце хода игрок сбрасывает карты до 7, лишние уходят в сброс, ход передаётся следующему (`currentPlayerId='p2'`, `hand.length=7`, `discard.length=1`).

**Фактическое поведение:** `400 BAD_REQUEST 'Hand limit exceeded: 8/7'`, ход остаётся у `p1`, рука остаётся 8 карт, сброс пуст. Игрок застревает до ручного `POST /:id/discard`.

**Место:** `server/src/gameService.ts` L790–794.

**Серьёзность:** High — игрок не может завершить ход, партия встаёт без явного действия клиента.

**Доказательство невакуумности:** мутация M1 (замена `fail(...)` на `while (hand.length > limit) { discard.push(hand.pop()) }`) — ровно A3 зеленеет, A5 остаётся красным, откат побайтовый.

## BUG-02 — Отменённая Neigh карта возвращается в руку вместо сброса (High)

**Баг:** после отмены розыгрыша через Neigh карта остаётся в руке владельца; по правилам она должна уйти в сброс.

**Шаги воспроизведения:**
1. Партия на 2 игроков, `p1` с картой `u1` в руке, `p2` с `Neigh`, фаза `action`.
2. `POST /api/game/:id/playWithWindow {cardId:'u1'}` → окно с `cancelLevel:0`.
3. `react/neigh` от `p2` → `cancelLevel:1`.
4. Закрыть окно `POST /api/game/:id/resolvePending` (или дать таймеру истечь).

**Ожидаемое поведение:** текст Neigh — «Stop that player's card from being played and send it to the discard pile». Карта актора уходит в его сброс: `discard=['u1']`, `hand` без `u1`, стойло без `u1`; Neigh у `p2` израсходован.

**Фактическое поведение:** `hand=['u1']`, `discard=[]`, `stable=[]`. Карта вернулась в руку, эффекта отмены как таковой нет — при следующем розыгрыше она снова доступна.

**Место:** `server/src/gameService.ts` — ветка таймера `schedulePendingResolution` (L71–77) и ветка `resolvePendingNow` (~L2038). Обе вызывают только `moveRewoundPlayToDeck`, сброс не выполняется.

**Серьёзность:** High — нарушает текст карты и позволяет переигрывать отменённую карту без потери ресурса.

**Доказательство невакуумности:**
- M2 (фикс только в ветке таймера) — A5 **остаётся красным**: тест закрывает окно через REST, а не таймером.
- M2b (тот же фикс в ветке `resolvePendingNow`) — ровно A5 зеленеет, A3 остаётся красным, откат `BYTE_IDENTICAL`.
- Вывод: фикс обязателен **в двух местах**; одна ветка не покрывает вторую.

## Открытые вопросы к Аналитику

1. BUG-01: автосброс должен выбирать карты сам (случайно/по правилу) или открывать окно выбора игроку (`await_choice`)? Сейчас нет ни того, ни другого.
2. BUG-02: при перемотке (`rewindPlayCancel`) карта по правилу Даниила идёт на верх колоды — фикс сброса не должен её затронуть, нужен явный флаг в pending.
