## Фикстуры

- Карты — из `server/data/catalog.v2.json` как есть (`fromCatalog` + clone), кроме `u_swap_chosen`.
- Синтетика T5 вынужденная и мотивирована: единственная карта каталога с `destination_player:'chosen'` — `dirty_deal_spell`, а она окна реакции не открывает, поэтому путь «выбор через `prefill.playerId`» на данных v2 недостижим. Действие swap в синтетике — точная копия действия из каталога (`swapActionOf`), не придумано тестом.
- Колода на всех стендах непустая (`['z1','z2']`): при пустых колоде и сбросе `maybeEndOnDeckEmpty` закрывает партию и кейс перестаёт проверять swap.

## Невакуумность (мутации в `server/src/gameService.ts`, каждая в отдельном процессе)

| Мутация | Что ломается | Красные | Откат |
|---|---|---|---|
| M1 | `else if (swapReq.required)` → `if (false as boolean)`: 409 «нужен выбор» не отдаётся | **T1** (единственный) | BYTE_IDENTICAL, sha 73dda42d… |
| M2 | `if (swapChosen && !prefillPlayer)` → `if (false as boolean)`: выбор не попадает в `pending.prefill.playerId` | **T5** (единственный) | BYTE_IDENTICAL, sha 73dda42d… |
| M3 | строка `ctx.selectedPlayers[cardId] = swapChosen` обнулена: прямой путь без выбора | **T2** (единственный) | BYTE_IDENTICAL, sha 73dda42d… |

Каждая мутация роняет ровно один тест и только свой — три разных механизма транспорта покрыты раздельно.

T5 при этом держится на двух опорах сразу (M2 его краснит), а `pending.kind==='play'` в самом тесте — страж от вырождения кейса в копию T2.

## Замечания Бэкенду

1. Мутация M1 показала: ветка `swapReq.candidates.length === 0` (нет ни одного соперника с картами) отдаёт 409 с `options.players` по всем соперникам, включая тех, у кого рука пуста. Клиент покажет игроков, выбрать которых нельзя. Ожидание: `options.players` — по кандидатам, а не по всем соперникам. В сьют не включено: это другой дефект, нужна отдельная задача.
2. Порядок карт в руке после swap произвольный — если фронтенд рассчитывает на сохранение порядка, это надо явно оговорить в контракте.

## Чем не покрыто

- `prefill.playerId` проверен только синтетической картой (обоснование выше) — реальной карты v2 с окном реакции и `destination_player:'chosen'` в каталоге нет.
- Автопроход при `is_player_choice:false` для swap не проверялся.
