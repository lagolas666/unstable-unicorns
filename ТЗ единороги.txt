### **Техническое задание (ТЗ) на разработку онлайн-игры "Unstable Unicorns"**  
*(Полная версия, включающая все обсуждённые аспекты)*  

---

## **1. Общие положения**  
### **1.1. Цель игры**  
- Побеждает первый игрок, собравший в своём **стойле (Stable)** **N единорогов** (по умолчанию `7`, настраивается).  
- **Штрафные животные** (коты, панды, выдры и др.) **не учитываются** для победы.  

### **1.2. Игровые сущности**  
| Тип | Описание | Особенности |  
|------|------------|------------|  
| **Единороги** | Основные карты для победы | Подтипы: Basic, Magic, Nightmare и др. |  
| **Не-единороги** | Штрафные животные (коты, панды) | Не считаются для победы, игнорируют эффекты для единорогов |  
| **Улучшения** | Дают постоянные бонусы | Активируются при входе в стойло |  
| **Понижения** | Накладывают штрафы | Могут блокировать действия |  
| **Мгновенные карты** | Играются в ответ | Типы: Отмена, Супер Отмена, Перемотка, Защита |

## **2. Детализированные правила**  
### **2.1. Фазы хода**  
Каждый ход включает **6 обязательных фаз**:  

1. **Начало хода (Start Phase)**  
   - Активируются эффекты с триггером `on_turn_start`.  
   - Проверяется пропуск фаз (если у игрока есть карты с `"skip_phases": [...]`).  

2. **Добор карты (Draw Phase)**  
   - Игрок **обязан** взять 1 карту из колоды.  
   - Исключения:  
     - Если есть эффект `"skip_phases": ["draw"]`.  
     - Если карта изменяет правило (например, "вместо добора сбросьте 1 карту").  

3. **Розыгрыш карт (Play Phase)**  
   - Игрок выбирает **одно из действий**:  
     - Сыграть **1 карту единорога**.  
     - Сыграть **1 улучшение/понижение**.  
     - **Пропустить фазу**, взяв **дополнительную карту** и перейдя сразу в **Фазу конца хода**.  

4. **Мгновенные карты (Instant Phase)**  
   - Любой игрок может сыграть Instant-карту в ответ.  
   - **Приоритет ответа**: Последний сыгравший карту имеет право ответа первым.  
   - **Цепочка отмен**:  
     - Обычная Отмена → Супер Отмена → Перемотка.  
     - Карты с `"immune_to_neigh": true` нельзя отменить.  

5. **Сброс карт (Discard Phase)**  
   - Если у игрока > **лимита карт** (по умолчанию `7`), он сбрасывает излишки.  

6. **Конец хода (End Phase)**  
   - Активируются эффекты `on_turn_end`.  
   - Проверяется условие победы.

## **3. JSON-структура карт**  
*(Полная спецификация)*  

### **3.1. Обязательные поля**  
```json
{
  "id": "unique_id",  
  "name": "Название",  
  "type": "unicorn|upgrade|downgrade|instant|non_unicorn",  
  "subtype": "basic|magic|cat|panda|...",  
  "description": "Текст карты",  
  "counts_for_win": true/false, // Для non_unicorn  
  "blocks_unicorn_effects": true/false, // Для non_unicorn  
  "skip_phases": ["draw", "play"], // Какие фазы пропускает  
  "instant_immunity": true/false, // Защита от Instant  
  "effects": [ /* См. ниже */ ]  
}
```

### **3.2. Структура эффектов**  
```json
"effects": [
  {
    "type": "add|destroy|discard|return|swap|prevent|ignore|cancel",  
    "target": "self|opponent|any|all",  
    "source": "hand|deck|discard|stable",  
    "destination": "stable|hand|deck|discard",  
    "card_type": "unicorn|upgrade|downgrade|any",  
    "subtype_restriction": "basic|magic|...",  
    "quantity_required": 2, // Сколько карт нужно для активации  
    "quantity_affected": 1, // Сколько карт меняется  
    "is_optional": true/false, // Можно ли отказаться  
    "condition": "if|unless|when|while",  
    "trigger": "on_play|on_discard|on_destroy|on_turn_start|on_turn_end",  
    "cancel_priority": 1, // Для Instant (1=обычная отмена, 2=супер)  
    "immune_to_cancel": true/false // Можно ли отменить  
  }
]
```

### **3.3. Примеры карт**  
#### **Карта "Кот-Ворчун"**  
```json
{
  "name": "Grumpy Cat",  
  "type": "non_unicorn",  
  "subtype": "cat",  
  "effects": [
    {
      "type": "prevent",  
      "target": "self",  
      "prevented_action": "play",  
      "card_type": "upgrade",  
      "trigger": "while_in_stable"  
    }
  ],  
  "counts_for_win": false,  
  "blocks_unicorn_effects": true  
}
```

#### **Карта "Перемотка Времени"**  
```json
{
  "name": "Time Rewind",  
  "type": "instant",  
  "instant_subtype": "rewind",  
  "effects": [
    {
      "type": "cancel",  
      "target": "any",  
      "cancel_priority": 3, // Выше Супер Отмены (2)  
      "immune_to_cancel": true // Нельзя отменить  
    }
  ]  
}
```

3. Взаимодействия карт между собой
Между единорогами
Некоторые карты усиливают или ослабляют определённые типы единорогов (например, "все магические единороги получают +1 к защите").

Карты, разрушающие единорогов, могут активировать эффекты смерти (например, "если этот единорог разрушен, возьми 1 карту").

Кашмарные единороги могут блокировать эффекты других единорогов.

Между улучшениями и понижениями
Улучшения могут нейтрализовать понижения (например, "разрушает все понижения в загоне").

Понижения могут блокировать улучшения (например, "игнорирует эффекты улучшений").

Между мгновенными картами
Некоторые мгновенные карты могут отменять другие мгновенные карты.

Эффекты цепной реакции (например, "если эта карта отменена, разруши 1 карту").

Между разными типами карт
Некоторые карты запрещают играть определённые комбинации (например, "нельзя играть магических единорогов, если у вас есть улучшение").

Карты, зависимые от количества единорогов (например, "если у вас 5+ единорогов, разрушите 1 улучшение").

Итог
В игре присутствует большое разнообразие карт (единороги, улучшения, понижения, мгновенные), каждая из которых обладает уникальными эффектами.
Эффекты можно разделить на универсальные (взятие, сброс, разрушение) и специфические (взаимодействие с типами единорогов, улучшениями и понижениями).
Взаимодействия между картами могут быть синергичными (усиление эффектов) или конфликтными (блокировка, отмена).

Этот анализ охватывает все возможные типы эффектов без дублирования, с учётом обобщения (например, "N карт" вместо конкретных чисел).

Техническое задание (ТЗ) на разработку онлайн-игры "Unstable Unicorns" с поддержкой загрузки карт
1. Общее описание
Необходимо разработать онлайн-версию карточной игры Unstable Unicorns с возможностью:

Игры по стандартным правилам (базовая механика + дополнения).

Динамической загрузки карт через JSON/админку с универсальными атрибутами.

Обработки сложных эффектов (условные действия, выбор целей, триггеры).

2. Требования к системе
2.1. Базовый функционал игры
Лобби (создание комнат, настройка колод).

Игровой процесс (ходы, фазы, приоритеты).

Интерфейс (рука, стол, сброс, колода).

Мультиплеер (PvP, AI-боты).

2.3. Атрибуты эффектов (обязательные поля)
Параметр	Описание	Пример значения

target	Кто применяет эффект (self, opponent, any, all)	"opponent"
source	Откуда берутся карты (hand, deck, discard, stable)	"discard"
destination	Куда помещаются карты (stable, hand, deck, discard)	"stable"
card_type	Тип карты (unicorn, upgrade, downgrade, any)	"unicorn"

quantity_affected	Сколько карт изменяется (M)	1
is_optional	Можно ли отказаться от эффекта (true/false)	true
condition	Условие (if, unless, when, while)	"if"
trigger	Когда активируется (on_play, on_discard, on_destroy, on_turn_start)	"on_discard"
