# Журнал командировок — GUI версия (EXE)

Цель: простое приложение под Windows, которое позволяет:
- загрузить таблицу Excel с данными по командировкам;
- выбрать период (за неделю);
- просмотреть предварительно журнал;
- сохранить печатную форму в DOCX (Times New Roman, 12pt);
- отправить документ на печать через стандартное применение Windows.

Особенности
- Поля таблицы в Excel могут называться по разным вариантам:
  - ФИО / FIO / Employee
  - Дата / Date
  - Время / Time
  - Причина / Reason / Purpose
  - Подпись / Signature
- Период печати задаётся вручную: начальная дата и конечная дата (YYYY-MM-DD).
- Шрифт печати DOCX: Times New Roman, 12pt.
- На выходе один документ DOCX за выбранную неделю; кнопка печати отправляет документ на печать через Windows.

Как собрать .exe
- Установить зависимости, если ещё не установлены:
  - pip install -r requirements.txt
- Установить PyInstaller (один файл):
  - pip install pyinstaller
- Собрать exe:
  - pyinstaller --windowed --onefile gui_app.py
- Готовый исполняемый файл будет в dist/gui_app.exe
- При необходимости можно адаптировать скрипт под конкретную организацию и экспорт.

Файлы проекта
- gui_app.py — основное GUI-приложение на Tkinter.
- requirements.txt — зависимости проекта (pandas, openpyxl, python-docx).
- README_GUI.md — этот файл с инструкциями.
- Пример кoманды: pyinstaller --windowed --onefile gui_app.py
